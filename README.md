# Around The U.S.

## Descrição

Around The U.S. é uma aplicação web que permite ao usuário visualizar e gerenciar uma galeria de fotos de lugares. É possível editar as informações do perfil (nome e descrição), adicionar novos lugares com imagem e nome, curtir ou descurtir fotos, e excluir cartões criados.

## Funcionalidades

Editar perfil (nome e descrição)
Adicionar novo cartão de lugar
Curtir/descurtir cartões
Fechar pop-ups com Esc, clique no overlay ou botão de
fechar.

## Tecnologias

HTML5
CSS3 (Flexbox e Grid)
Metodologia BEM
JavaScript
